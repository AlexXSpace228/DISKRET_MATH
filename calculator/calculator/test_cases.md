# Тесты черного ящика

## Тестовые данные
Для функциональных проверок задать `U = {1, 2, 3, 4}`, `A = {1, 2, 3}`, `B = {3, 4}`, `C = {}`, `D = {3}`, `E = {1, 2, 3, 4}`. Все множества формируются через пункт меню «ввод с клавиатуры».

| ID | Проверяемое требование | Действия / входные данные | Ожидаемый результат |
|---|---|---|---|
| BB-01 | Ручной ввод U и удаление повторов | Для U указать 4 элемента: `1, 2, 2, 4`; показать все множества | `U = {1, 2, 4}`, повтор `2` не появляется второй раз |
| BB-02 | Проверка целочисленного ввода | При вводе элемента множества указать `1.5`, затем `1` | Выводится ошибка целого числа, запрос повторяется, в множество попадает только `1` |
| BB-03 | Ограничение подмножества универсумом | При вводе элемента A указать `9`, затем `2` при `U = {1, 2, 3, 4}` | Значение `9` отвергается; после повторного ввода A содержит `2` |
| BB-04 | Пересечение | Выполнить `A ∩ B` для тестовых данных | Результат `{3}` |
| BB-05 | Объединение | Выполнить `A ∪ B` | Результат `{1, 2, 3, 4}`, без повторов |
| BB-06 | Разность | Выполнить `A \\ B` | Результат `{1, 2}`; порядок операндов сохраняет смысл разности |
| BB-07 | Симметрическая разность | Выполнить `A △ B` | Результат `{1, 2, 4}` |
| BB-08 | Дополнение | Найти дополнение A относительно U | Результат `{4}` |
| BB-09 | Проверка принадлежности | Для A проверить `2`, затем `4` | Для `2` сообщается принадлежность, для `4` — отсутствие в A |
| BB-10 | Истинное включение | Проверить `D ⊆ B`, затем `C ⊆ A` | В обоих случаях сообщается, что включение выполняется, в том числе для пустого множества |
| BB-11 | Ложное включение | Проверить `A ⊆ B` | Сообщается, что включение не выполняется |
| BB-12 | Генерация U с граничным количеством | Случайно сформировать U из диапазона `[5, 5]`, указать количество `1` | U содержит ровно `{5}` |
| BB-13 | Отказ от невозможного размера генерации | Для диапазона `[1, 2]` указать количество U `3`, затем `2` | Первое количество отвергается с ошибкой; после повторного ввода U содержит два уникальных элемента из диапазона |
| BB-14 | Случайная генерация подмножества | Для `U = {1, 2, 3, 4}` случайно создать A размера `4` | A содержит каждый элемент U ровно один раз |
| BB-15 | Пустое множество и пустое дополнение | Задать `U = {}` и проверить дополнение пустого A | Результат дополнения — `{}`; приложение продолжает работать |
| BB-16 | Проверка последовательности настройки | До задания U выбрать настройку A или бинарную операцию | Печатается требование сначала задать U; приложение не завершается с ошибкой |

Для тестов с генератором проверяются инварианты (границы диапазона, требуемая мощность, уникальность и включение в U), а не конкретная последовательность случайных чисел.
